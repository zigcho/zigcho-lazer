# lazer caught up

zigcho!lazer is now based on osu! **2026.921.0**, instead of the august build.

this brings in the new upstream fixes for song select, chat, the editor, ranked play and replay handling. our kai login, multiplayer, profiles, medals, leaderboards, relax / ap views and map submission changes are still here.

the client now uses .net 10. the desktop packages still include the runtime, so there's nothing extra to install. android targets api 36; the unsigned ios build uses the newer xcode toolchain.

i've kept the separate zigcho storage and app identity. it still has no installer and won't update or replace an official osu! install. keep the whole extracted folder together when updating.

this updates the client, not the server's pp policy. no custom relax or ap calculator changes in this release.
